# Media Organizer

Плагин для Obsidian, который наводит порядок в галерее хранилища: переименовывает фото и видео по названию заметки, в которую они вставлены, добавляет индекс и раскладывает файлы по папкам-годам.

```
Gallery/IMG_4411.JPG                →  Gallery/2024/гремучая_смесь_001.jpg
Gallery/photo_7@15-03-2019.jpg      →  Gallery/2019/2019-03-15_15-20-21_001.jpg
```

Дизайн интерфейса: `docs/design.svg`.

## Установка

1. Скопируйте папку `media-organizer` целиком в `<хранилище>/.obsidian/plugins/`.
2. Перезапустите Obsidian (или обновите список плагинов).
3. Включите **Media Organizer** в «Настройки → Сторонние плагины».

Сборка не нужна: `main.js` при старте сам подключает модули из папки `src/`, поэтому папку нужно копировать вместе с `src/`. Требуется Obsidian 1.4.10 или новее. Работает на десктопе и на мобильных.

## Быстрый старт

1. Откройте окно плагина: значок «картинки» на боковой панели или команда **Открыть Media Organizer**.
2. Выберите папки для уборки (начните вводить название, появятся подсказки).
3. Укажите свойства заметки с датой.
4. Нажмите **Сканировать**. Плагин покажет таблицу «было → станет» и ничего не изменит.
5. Если нужно, ответьте на вопросы о форматах дат.
6. Проверьте таблицу, снимите галочки с лишнего и нажмите **Применить**.

Рекомендуется первый раз попробовать на копии хранилища или на одной небольшой папке.

## Как формируются имена и папки

- Имя файла = название родительской заметки + индекс: `гремучая_смесь_001.jpg`. Родительская заметка — та, в которую файл вставлен.
- Пробелы заменяются на `_`. Символы `\ / : * ? " < > | # ^ [ ]` удаляются. Регистр сохраняется (можно включить строчные буквы).
- Расширение приводится к нижнему регистру (`.JPG` → `.jpg`).
- Индексы идут в порядке появления файлов в заметке. Количество цифр настраивается (2–4).
- Папка года создаётся внутри выбранной папки: `<папка>/ГГГГ/`. Если выбрано «всё хранилище», папки годов появятся в корне.
- Если файл вставлен в несколько заметок, а в других только упомянут ссылкой, родителем считается заметка со вставкой (`![]`).

## Откуда берётся дата

1. Плагин перебирает **свойства с датой** по приоритету и использует первое, значение которого удалось прочитать. Свойства могут быть в разных форматах.
2. Если ни одного из них в заметке нет — берётся дата создания заметки (можно отключить, тогда такие файлы пропускаются).

Для папок важен только год. Распознаются форматы:

| Пример | Комментарий |
|---|---|
| `2024-05-01`, `2024.5.1`, `2024/05/01`, `2024-05-01T10:00:00Z` | дата берётся как записана, без учёта часовых поясов |
| `20240501`, `20240501_101010` | |
| `21.10.2023`, `10/21/2023` | год из четырёх цифр |
| `21 октября 2022`, `15 марта 2019, 15:20`, `Oct 21, 2020`, `март 2018` | русские и английские названия месяцев |
| `2024`, `2024-05` | |
| Unix-время (10 или 13 цифр), `[[2016-01-02]]`, списки | |

Плагин спрашивает пользователя только когда трактовка меняет год: двузначный год вроде `05.06.07` (2007 или 2005?) или значение, которое не удалось прочитать. Вопрос появляется после сканирования, ответ запоминается (сбросить можно в настройках).

## Что происходит при переносе

- Файлы переименовываются штатными средствами Obsidian, поэтому **ссылки и вложения в заметках обновляются автоматически**. Для этого в «Настройки → Файлы и ссылки» должна быть включена опция «Автоматически обновлять внутренние ссылки».
- Формат обновлённой ссылки зависит от вашей настройки «Формат новых ссылок» (кратчайший путь, относительный или абсолютный).
- Если путь назначения уже занят, файл получает следующий свободный индекс.
- Последнюю уборку можно откатить кнопкой **Отменить последнюю** или командой «Отменить последнюю уборку». Откат возвращает файлы на прежние места и тоже обновляет ссылки. Хранится только последний запуск.

## Повторный запуск

- Файлы, которые уже названы по схеме и лежат в нужной папке-году, получают статус «На месте» и не трогаются.
- Новые файлы из тех же заметок получают следующий свободный индекс (`_004` и т. д.), старые номера не пересчитываются.
- После переименования заметки или смены даты файлы будут переименованы и перемещены заново.

## Статусы в таблице

| Статус | Значение |
|---|---|
| К переносу | файл будет переименован и перемещён |
| На месте | уже организован |
| Конфликт | файл вставлен в несколько заметок (в причине указаны названия) |
| Без заметки | файл не вставлен ни в одну заметку, не трогается |
| Нет даты | в заметке нет читаемой даты, а дата создания отключена или выбран пропуск |
| Нужен выбор | ответ на вопрос о формате даты не получен |
| Перенесён / Ошибка | результат применения |

## Настройки

| Настройка | Описание |
|---|---|
| Папки для уборки | где искать файлы; можно несколько, с автоподстановкой |
| Свойства с датой | список свойств по приоритету; имена подсказываются из хранилища |
| Дата создания, если поля нет | запасной источник даты |
| Файл в нескольких заметках | пропускать как конфликт или брать самую раннюю заметку |
| Количество цифр в индексе | 2, 3 или 4 |
| Имена строчными буквами | по умолчанию регистр сохраняется |
| Расширения медиафайлов | по умолчанию фото и видео; SVG не включён |
| Сбросить запомненные ответы | плагин снова спросит про неоднозначные форматы |

## Ограничения и подсказки

- Плагин работает с файлами, которые вставлены или упомянуты в заметках `.md`. Ссылки в Canvas и во фронтматтере не учитываются.
- Если рядом стоят плагины, которые сами создают папки или перекладывают вложения (например, по шаблону вида `2014-10-October`), отключите их на время уборки.
- Если что-то не работает, откройте консоль разработчика (Ctrl+Shift+I / Cmd+Opt+I) и проверьте ошибки с `media-organizer` или `Media Organizer`.

## Структура

```
media-organizer/
├── manifest.json        описание плагина
├── main.js              загрузчик модулей из src/
├── styles.css           стили по макету
├── docs/design.svg      макет интерфейса
└── src/
    ├── main.js          запуск, команды, настройки, откат
    ├── view.js          окно плагина
    ├── settings.js      вкладка настроек и значения по умолчанию
    ├── scanner.js       поиск файлов и родительских заметок
    ├── planner.js       план: даты, имена, индексы, статусы
    ├── dateParser.js    разбор дат в любом формате
    ├── namer.js         формирование имён
    ├── executor.js      перенос и откат
    ├── folderSuggest.js выбор папок с автоподстановкой
    ├── propertyPicker.js выбор свойств с датой
    ├── modals.js        диалоги подтверждения и вопросов о датах
    └── utils.js         вспомогательные функции
```

Для правок изменяйте файлы в `src/` и перезапускайте плагин: сборка не требуется.
