# Media Organizer

Плагин для Obsidian, который наводит порядок в галерее хранилища: переименовывает фото и видео по названию заметки, в которую они вставлены, добавляет индекс и раскладывает файлы по папкам-годам. Находит медиа, на которые никто не ссылается, и даёт удалить их по одному или пачкой. Ведёт статистику уборок с инфографикой.

```
Gallery/IMG_4411.JPG                →  Gallery/2024/гремучая_смесь_001.jpg
Gallery/photo_7@15-03-2019.jpg      →  Gallery/2019/2019-03-15_15-20-21_001.jpg
```

Дизайн интерфейса: `docs/design.svg`.

## Установка

1. Скопируйте папку `media-organizer` целиком в `<хранилище>/.obsidian/plugins/`.
2. Перезапустите Obsidian (или обновите список плагинов).
3. Включите **Media Organizer** в «Настройки → Сторонние плагины».

**Обновление.** Для работы плагина достаточно трёх файлов: `main.js`, `manifest.json` и `styles.css`. `main.js` уже содержит всю логику, папка `src/` ему не нужна. Скопируйте файлы поверх старых, затем выключите и снова включите плагин (или перезапустите Obsidian) и закройте старую вкладку Media Organizer. Версия показана в заголовке окна, а загрузку подтверждает строка `[Media Organizer] загружен, версия …` в консоли (Ctrl+Shift+I / Cmd+Opt+I).

Установщики плагинов, которые копируют только стандартные три файла, тоже подходят. Требуется Obsidian 1.4.10 или новее. Работает на десктопе и на мобильных.

## Вкладки окна плагина

| Вкладка | Что делает |
|---|---|
| **Уборка** | сканирует папки, показывает «было → станет», переименовывает и раскладывает по годам |
| **Без ссылок** | ищет медиа, на которые не ссылается ни одна заметка, и удаляет их (выборочно) |
| **Статистика** | инфографика по всем уборкам, список последних запусков, сохранение инфографики в SVG |

## Быстрый старт

1. Откройте окно плагина: значок «картинки» на боковой панели или команда **Открыть Media Organizer**.
2. Выберите папки для уборки (начните вводить название, появятся подсказки).
3. Укажите свойства заметки с датой.
4. Нажмите **Сканировать**. Плагин покажет таблицу «было → станет» и ничего не изменит.
5. Если нужно, ответьте на вопросы о форматах дат.
6. Проверьте таблицу, снимите галочки с лишнего и нажмите **Применить**.

Рекомендуется первый раз попробовать на копии хранилища или на одной небольшой папке.

## Как формируются имена и папки

- Имя файла = название родительской заметки + индекс: `гремучая_смесь_001.jpg`. Родительская заметка — та, в которую файл вставлен.
- Пробелы заменяются на `_`. Символы `\ / : * ? " < > | # ^ [ ]` удаляются. Регистр сохраняется (можно включить строчные буквы).
- Расширение приводится к нижнему регистру (`.JPG` → `.jpg`).
- Индексы идут в порядке появления файлов в заметке. Количество цифр настраивается (2–4).
- Папка года создаётся внутри выбранной папки: `<папка>/ГГГГ/`. Если выбрано «всё хранилище», папки годов появятся в корне.
- Если Obsidian не считает файл вложением (например, видео вставлено HTML-тегом `<video src="…">`, указано в свойстве или просто в тексте), плагин ищет имя файла в тексте заметок и берёт заметку, где оно упомянуто, как родительскую. Такие файлы помечены подсказкой в таблице. При переносе плагин сам правит упоминание в тексте заметки, потому что Obsidian такие ссылки не обновляет. Откат возвращает и файлы, и текст заметок.
- Если файл вставлен в несколько заметок, а в других только упомянут ссылкой, родителем считается заметка со вставкой (`![]`).

## Откуда берётся дата

1. Плагин перебирает **свойства с датой** по приоритету и использует первое, значение которого удалось прочитать. Свойства могут быть в разных форматах.
2. Если ни одного из них в заметке нет — берётся дата создания заметки (можно отключить, тогда такие файлы пропускаются).

Для папок важен только год. Распознаются форматы:

| Пример | Комментарий |
|---|---|
| `2024-05-01`, `2024.5.1`, `2024/05/01`, `2024-05-01T10:00:00Z` | дата берётся как записана, без учёта часовых поясов |
| `20240501`, `20240501_101010` | |
| `21.10.2023`, `10/21/2023` | год из четырёх цифр |
| `21 октября 2022`, `15 марта 2019, 15:20`, `Oct 21, 2020`, `март 2018` | русские и английские названия месяцев |
| `2024`, `2024-05` | |
| Unix-время (10 или 13 цифр), `[[2016-01-02]]`, списки | |

Плагин спрашивает пользователя только когда трактовка меняет год: двузначный год вроде `05.06.07` (2007 или 2005?) или значение, которое не удалось прочитать. Вопрос появляется после сканирования, ответ запоминается (сбросить можно в настройках).

## Что происходит при переносе

- Файлы переименовываются штатными средствами Obsidian, поэтому **ссылки и вложения в заметках обновляются автоматически**. Для этого в «Настройки → Файлы и ссылки» должна быть включена опция «Автоматически обновлять внутренние ссылки».
- Формат обновлённой ссылки зависит от вашей настройки «Формат новых ссылок» (кратчайший путь, относительный или абсолютный).
- Если путь назначения уже занят, файл получает следующий свободный индекс.
- Последнюю уборку можно откатить кнопкой **Отменить последнюю** или командой «Отменить последнюю уборку». Откат возвращает файлы на прежние места и тоже обновляет ссылки. Хранится только последний запуск.

## Повторный запуск

- Файлы, которые уже названы по схеме и лежат в нужной папке-году, получают статус «На месте» и не трогаются.
- Новые файлы из тех же заметок получают следующий свободный индекс (`_004` и т. д.), старые номера не пересчитываются.
- После переименования заметки или смены даты файлы будут переименованы и перемещены заново.

## Медиа без ссылок

Вкладка **Без ссылок** ищет в выбранных папках файлы, на которые не ссылается ни одна заметка.

1. Нажмите **Найти**. Плагин покажет список с миниатюрами, размером и датой изменения. Сортировать можно по размеру, дате и пути, фильтровать по фото и видео. Клик по миниатюре или кнопка «Открыть» показывает файл, чтобы вы могли решить, нужен ли он.
2. Включите **Разрешить удаление**. По умолчанию удаление выключено, то же самое переключатель в настройках плагина.
3. Отметьте файлы галочками и нажмите **Удалить выбранные** или удалите один файл кнопкой с корзиной в строке. Перед удалением плагин просит подтверждение и показывает количество и объём.

Как плагин защищает нужные файлы:
- Кроме ссылок, которые знает Obsidian, плагин ищет имя файла в тексте всех заметок, Canvas и баз (`.md`, `.canvas`, `.base`). Файл, упомянутый в свойстве, в Canvas или обычным текстом, считается используемым и в список не попадает. Их число показано как «Защищено».
- Непосредственно перед удалением ссылки проверяются ещё раз. Если пока вы выбирали, на файл появилась ссылка, он не удаляется, а в строке будет пояснение.
- Файлы уходят в корзину **по настройке Obsidian** «Файлы и ссылки → Удалённые файлы» (системная корзина, папка `.trash` или безвозвратно). Плагин не может вернуть их сам: если хотите иметь возможность восстановить, проверьте эту настройку заранее.

## Статистика и инфографика

Каждая уборка, удаление и откат записываются в статистику (последние 1000 записей, хранятся в `data.json` плагина). Вкладка **Статистика** показывает:

- число уборок, откатов, упорядоченных и удалённых файлов, освобождённое место и ошибки;
- файлы по годам (если лет больше 12, самые ранние сворачиваются в одну строку);
- долю фото и видео;
- динамику по месяцам за последние 12 месяцев (упорядочено и удалено);
- таблицу последних десяти запусков.

Кнопка **Сохранить инфографику (SVG)** кладёт инфографику в хранилище отдельным файлом `Статистика уборок ГГГГ-ММ-ДД.svg` и открывает его. Папка настраивается («Папка для инфографики», по умолчанию `Media Organizer`). Файл можно вставить в любую заметку: `![[Статистика уборок 2026-10-23.svg]]`. Повторное сохранение в тот же день перезаписывает файл. Кнопка **Очистить статистику** удаляет только записи о запусках, файлы остаются.

## Статусы в таблице

| Статус | Значение |
|---|---|
| К переносу | файл будет переименован и перемещён |
| На месте | уже организован |
| Конфликт | файл вставлен в несколько заметок (в причине указаны названия) |
| Без заметки | имя файла не найдено ни в одной заметке, на вкладке «Уборка» он не трогается; кнопка в строке открывает вкладку «Без ссылок», где его можно удалить |
| Нет даты | в заметке нет читаемой даты, а дата создания отключена или выбран пропуск |
| Нужен выбор | ответ на вопрос о формате даты не получен |
| Перенесён / Ошибка | результат применения |

## Настройки

| Настройка | Описание |
|---|---|
| Папки для уборки | где искать файлы; можно несколько, с автоподстановкой |
| Свойства с датой | список свойств по приоритету; имена подсказываются из хранилища |
| Дата создания, если поля нет | запасной источник даты |
| Файл в нескольких заметках | пропускать как конфликт или брать самую раннюю заметку |
| Количество цифр в индексе | 2, 3 или 4 |
| Имена строчными буквами | по умолчанию регистр сохраняется |
| Расширения медиафайлов | по умолчанию фото и видео; SVG не включён |
| Разрешить удаление медиа без ссылок | включает кнопки удаления на вкладке «Без ссылок»; по умолчанию выключено |
| Папка для инфографики | куда сохранять SVG со статистикой |
| Сбросить запомненные ответы | плагин снова спросит про неоднозначные форматы |

## Ограничения и подсказки

- Уборка работает с файлами, которые вставлены или упомянуты в заметках `.md`. Ссылки в Canvas на вкладке «Уборка» не учитываются.
- Поиск «без ссылок» не знает о ссылках из CSS-сниппетов, скриптов и других плагинов. Если такие файлы лежат в выбранных папках, не выбирайте эти папки для удаления или удаляйте файлы только вручную по списку.
- Если рядом стоят плагины, которые сами создают папки или перекладывают вложения (например, по шаблону вида `2014-10-October`), отключите их на время уборки.
- Если что-то не работает, откройте консоль разработчика (Ctrl+Shift+I / Cmd+Opt+I) и проверьте ошибки с `media-organizer` или `Media Organizer`.

## Структура

```
media-organizer/
├── manifest.json        описание плагина
├── main.js              готовый плагин (собран из src/)
├── styles.css           стили по макету
├── docs/design.svg      макет интерфейса
├── tools/build.js       сборка main.js из src/ (необязательно)
└── src/
    ├── main.js          запуск, команды, настройки, откат
    ├── view.js          окно плагина: шапка, вкладки, вкладка «Уборка»
    ├── settings.js      вкладка настроек и значения по умолчанию
    ├── scanner.js       поиск файлов и родительских заметок
    ├── planner.js       план: даты, имена, индексы, статусы
    ├── dateParser.js    разбор дат в любом формате
    ├── namer.js         формирование имён
    ├── executor.js      перенос и откат
    ├── folderSuggest.js выбор папок с автоподстановкой
    ├── propertyPicker.js выбор свойств с датой
    ├── tabOrphans.js    вкладка «Без ссылок»
    ├── tabStats.js      вкладка «Статистика»
    ├── orphans.js       поиск медиа без ссылок, упоминания в тексте, родители по тексту
    ├── refs.js          правка и откат упоминаний файла в тексте заметок
    ├── stats.js         записи о запусках и сводка
    ├── statsSvg.js      инфографика в виде SVG
    ├── modals.js        диалоги подтверждения и вопросов о датах
    └── utils.js         вспомогательные функции
```

Исходники лежат в `src/`, готовый `main.js` собирается из них командой `node tools/build.js`. Это нужно только тем, кто правит код, для обычной установки ничего запускать не надо.
